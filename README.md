### 📈 2. Neuro-Hedge — Reinforcement Learning Research

A deep reinforcement learning research project exploring option hedging through a simulated financial environment.

**Key Features**
- Deep Deterministic Policy Gradient (DDPG).
- Custom Gymnasium environment using Geometric Brownian Motion.
- Actor–Critic architecture implemented with PyTorch.
- Exploration using Ornstein–Uhlenbeck noise.

**Tech Stack:** `Python` `PyTorch` `Reinforcement Learning` `Gymnasium` `NumPy`

### 🛡️ 3. CreditGuard AI — Credit Risk Assessment

An end-to-end machine learning project designed to estimate credit risk and make model predictions easier to interpret.

**Key Features**
- Credit risk prediction using XGBoost.
- Model explainability using SHAP.
- FastAPI-based prediction services.
- Streamlit dashboard for interactive analysis.

**Tech Stack:** `Python` `XGBoost` `SHAP` `FastAPI` `Streamlit`
